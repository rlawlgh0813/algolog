# AlgoLog Backend

AlgoLog는 알고리즘 문제 풀이를 구조적으로 기록하고 관리하기 위한 백엔드 프로젝트입니다.

기존 블로그형 기록 방식은 자유롭게 작성할 수 있다는 장점이 있지만, 문제 번호, 플랫폼, 난이도, 태그, 반례, 오답 원인, 복습 필요 여부 같은 정보를 체계적으로 관리하고 다시 찾아보는 데에는 불편함이 있었습니다.  
이 프로젝트는 이러한 불편함을 해결하기 위해, **문제 정보 / 풀이 기록 / 반례 / 복습 메모**를 구조화하여 저장하고 탐색할 수 있는 서비스를 만드는 것을 목표로 합니다.

---

## 프로젝트 목표

- 알고리즘 문제 풀이를 블로그 글보다 더 구조적으로 기록하기
- 풀이 자체뿐 아니라 **왜 틀렸는지**, **어떤 반례에서 실패했는지**, **어떻게 수정했는지**까지 기록하기
- 문제 번호, 플랫폼, 난이도, 태그 등을 기준으로 다시 찾기 쉽게 만들기
- 공개/비공개 설정을 통해 다른 사용자의 풀이도 탐색할 수 있도록 확장 가능하게 설계하기

---

## 핵심 기능

### 1. 사용자 기능
- 회원가입
- 로그인

### 2. 문제 관리
- 문제 등록
- 문제 조회
- 플랫폼 / 문제 번호 / 난이도 기반 관리

### 3. 풀이 기록 관리
- 내 풀이 작성
- 내 풀이 목록 조회
- 풀이 상세 조회
- 풀이 수정 / 삭제
- 해결 상태 기록
- 복습 필요 여부 기록
- 공개 / 비공개 설정

### 4. 반례 기록 관리
- 실패한 테스트케이스(반례) 작성
- 오답 원인 기록
- 수정 메모 기록
- 풀이와 연결된 반례 조회

### 5. 탐색 기능
- 공개된 다른 사용자 풀이 조회
- 플랫폼 / 난이도 / 해결 상태 / 복습 필요 여부 기반 필터
- 문제 번호 기반 검색
- 특정 문제의 공개 풀이 조회

--

## 도메인 구조

이 프로젝트는 아래 도메인을 중심으로 설계합니다.

- **User**  
  사용자 정보

- **Problem**  
  문제 자체의 메타데이터  
  (플랫폼, 문제 번호, 제목, 난이도 등)

- **SolutionRecord**  
  특정 사용자의 문제 풀이 기록  
  (풀이 내용, 실수 포인트, 해결 상태, 복습 필요 여부, 공개 여부 등)

- **CounterExample**  
  풀이 과정에서 실패했던 테스트케이스 / 반례  
  (입력 예시, 기대 동작, 오답 원인, 수정 메모 등)

## 개발 방향

이 프로젝트는 백엔드 취업용 포트폴리오를 목표로 하며,  
아래와 같은 점을 중요하게 생각합니다.

- 단순 기능 구현이 아니라 **설명 가능한 설계**
- 도메인 중심의 엔티티 분리
- CRUD + 인증 + 검색/필터 + 예외 처리 등 백엔드 기본기 반영
- 추후 확장이 가능한 구조
